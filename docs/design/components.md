# רכיבים

קטלוג הרכיבים שמופיעים בפועל בעיצובים, עם המיפוי שלהם ל-shadcn/ui. כל דוגמת קוד לקוחה מהייצוא של Stitch.

---

## כפתורים

| סוג             | מראה                                                                                 | מתי                                                           |
| --------------- | ------------------------------------------------------------------------------------ | ------------------------------------------------------------- |
| **Primary**     | רקע `primary` (`#000613`), טקסט לבן, רדיוס `lg`, ריפוד `px-6 py-3`, לעיתים עם אייקון | פעולה ראשית אחת לכל מסך: "אשר הזמנה", "סגירת גיליון", "שמירה" |
| **Secondary**   | רקע שקוף, גבול 1px `outline-variant`, טקסט `on-surface`                              | "שמור טיוטה", "בדיקת הגיליון", "ביטול"                        |
| **Ghost**       | טקסט בלבד `on-surface-variant`, ללא גבול                                             | "ביטול" בתוך כרטיסים                                          |
| **Destructive** | רקע `error-container`, טקסט `error`, אייקון `delete`                                 | "הסר שיבוץ"                                                   |
| **Gold**        | רקע `secondary-container`                                                            | שמור למצב פעיל/מודגש — **לא בשימוש ככפתור בעיצובים הנוכחיים** |

shadcn: `Button` עם `variant="default" | "outline" | "ghost" | "destructive"`.

## Status badges

הרכיב הכי נפוץ במערכת. גלולה (`rounded-full`), `text-xs font-bold`, ריפוד `px-2.5 py-1`, עם אייקון 14px אופציונלי.

```html
<span
  class="inline-flex items-center gap-1 px-2.5 py-1 rounded-full
             bg-[#E6F4EA] text-[#137333] text-xs font-bold"
>
  <span class="material-symbols-outlined text-[14px]">check_circle</span>
  שובץ
</span>
```

### מיפוי מלא של סטטוסים לצבעים

הצבעים לפי `design-system.md` §1. הטבלה מכסה את כל ה-enums מ-`erd.md`:

**סטטוס פרסום** (`Publication.status`)

| ערך                | תווית       | סגנון   |
| ------------------ | ----------- | ------- |
| `planned`          | מתוכנן      | neutral |
| `missing_ad`       | חסר חומר    | error   |
| `ad_received`      | חומר התקבל  | success |
| `ready_for_layout` | מוכן לשיבוץ | success |
| `placed`           | שובץ        | success |
| `published`        | פורסם       | success |
| `canceled`         | בוטל        | neutral |
| `billed`           | חויב        | neutral |

**סטטוס שיבוץ** (`placement_status`) — `not_placed` = warning · `placed` = success

**סטטוס תשלום** — `unpaid` = neutral ("לא שולם") · `partially_paid` = warning ("שולם חלקית") · `paid` = success ("שולם") · `debt` = **debt/gold** ("חוב פתוח"); חוב שעבר את זמנו מוצג כ-error ("חוב אקטיבי")

**סטטוס הזמנה** — `draft` = neutral · `pending_approval` = warning · `approved` = success · `rejected` = error · `canceled` = neutral · `completed` = success

**סטטוס גיליון** — `draft` = neutral · `in_layout` = warning ("בעבודה") · `ready_for_print` = success · `closed` = neutral

> ⚠️ התווית **"ממתין להגהה"** שמופיעה בעיצובים היא המצאה של Stitch — אין מצב כזה ב-FR-4. לא מממשים אותה.

shadcn: `Badge` עם variants מותאמים.

## כרטיס KPI

מלבן לבן, גבול 1px, ריפוד 16px, עם **גבול צדדי עבה בצבע סמנטי**.

מבנה: שורה עליונה = אייקון + תווית (`caption`, `on-surface-variant`); מתחת = מספר גדול (`headline-lg`, Libre Caslon).

- מדדים ניטרליים — גבול `outline-variant`, מספר `on-surface`
- מדדי אזהרה — גבול/מספר `secondary`
- מדדי בעיה — גבול/מספר `error`

בגרסת הגבייה (`04-billing`) הכרטיסים גדולים יותר וכוללים גם צ'יפ מגמה (`8.1%↑`) ופס התקדמות.

## טבלת נתונים

- כותרת: רקע `surface-container`, טקסט `caption` bold, `on-surface-variant`
- שורה: רקע לבן, ריפוד `px-5 py-3`, גבול תחתון בלבד `outline-variant`
- Hover: `surface-container-low`
- **שורה עם בעיה: רקע אדמדם עדין** (`bg-red-50/40`) — משמש לחוב ולחומר חסר
- שורה נבחרת/מורחבת: רקע `surface-container-high` + גבול צדדי `secondary`
- עמודת הלקוח: אווטאר עגול עם אות ראשונה + שם ב-`font-medium`
- כפתור "טען עוד" ממורכז בתחתית

**עריכה inline:** בטבלת הגבייה, לחיצה על שורה פותחת שורה מורחבת מתחתיה עם שדות קלט ("סכום ששולם", "תאריך תשלום אחרון", "מספר חשבונית", "סטטוס") וכפתורי שמירה/ביטול. דפוס טוב — כדאי לשמר אותו לכל עריכה מהירה.

shadcn: `Table` + `Collapsible` לשורה המורחבת.

## שדות קלט

- רקע `surface-container` או לבן עם גבול 1px `outline-variant`
- רדיוס `lg` (8px), ריפוד `px-4 py-3`
- תווית **מעל** השדה תמיד, `caption` bold
- Placeholder ב-`outline`
- Focus: גבול `primary` + זוהר זהב עדין 2px
- שדות חיפוש: אייקון `search` בקצה
- Dropdown: אייקון `expand_more` בקצה שמאל

## אזור העלאת קבצים

```
גבול מקווקו 2px · רדיוס lg · רקע surface-container-low · ריפוד גדול · ממורכז
  אייקון cloud_upload בעיגול
  כותרת bold:  "גרירת קבצים לכאן"
  משנה caption: "או לחץ לבחירת קבצים מהמחשב"
  כפתור secondary: "בחירת קובץ"
```

לצידו כרטיס דרישות כחלחל (`surface-container`) עם אייקון `info` ורשימת תבליטים: פורמטים, רזולוציה, מודל צבע, גודל מקסימלי, bleed.

> ⚠️ **הרכיב נשאר, התוכן מוחלף.** הדרישות שמופיעות בעיצוב (`300dpi`, `CMYK`, `bleed 5mm`) הן המצאה של Stitch ולא מגיעות למימוש. הגודל המקסימלי נטען דינמית מ-`Newspaper.max_ad_file_size` (FR-21), לא כמספר קשיח. מה שנשאר: הפורמטים המותרים (PDF/JPG/PNG) והגודל המרבי של העיתון שנבחר.

## כרטיס קובץ מודעה

תמונה ממוזערת למעלה, ומתחתיה שם קובץ, שם לקוח (`caption`), שורת מטא-דאטה (סוג + גודל, ב-`label-sm` מונו), ותחתית עם אווטאר המעלה + זמן.

- קובץ תקין: גבול `outline-variant`
- קובץ עם בעיה: **גבול אדום + פס אדום בצד + באנר שגיאה** בתוך הכרטיס עם אייקון `info` וטקסט השגיאה
- badge סטטוס בפינה העליונה

מתג תצוגה גריד/רשימה מופיע מעל האוסף.

## נאב-סטריפ עמודים

רצועת תמונות ממוזערות בתחתית הקנבס. כל תמונה = מיניאטורה סכמטית של פריסת העמוד (מלבנים כחלחלים), ומתחתיה תווית: `עמוד 1 (שער)`, `עמוד 2-3`, `עמוד 4`, `עמוד 5`. העמוד הפעיל בגבול `primary` עבה. בקצה — כרטיס מקווקו עם `+` להוספת עמוד.

## מודאל

- רוחב ~500px (מרכזי) — או פאנל צד ברוחב ~500px בגובה מלא
- רדיוס `xl`, `Elevation 2`
- כותרת: `headline-md` ממורכזת + `✕` בקצה
- תחתית דביקה: פעולה ראשית + ביטול
- רקע מוכהה מאחורי

## פערי רכיבים

רכיבים שה-PRD דורש ואין להם עיצוב:

- **בורר עסק פעיל** (FR-2)
- **מודאל בדיקת גיליון** — 7 סוגי הממצאים מ-US-008
- **טופס לקוח** ומסך המרת מזדמן→קבוע (US-002)
- **עורך תבנית שיבוץ / גריד** (US-006) — הכי מורכב מבין החסרים
- **מטריצת מחירון** (עיתון × סוג עמוד × צורת פרסום)
- **מסך אישור/דחיית הזמנה** עם שדה סיבת דחייה (US-004, FR-19)
- **מצבי ריק, טעינה ושגיאה** — אין אף אחד מהם באף מסך
- **מצב מובייל/טאבלט** — כל העיצובים בדסקטופ בלבד
