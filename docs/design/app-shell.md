# App Shell — מעטפת המערכת

המעטפת זהה בכל המסכים הפנימיים. פורטל הלקוח משתמש במעטפת שונה לחלוטין (ראה סוף המסמך).

מקור: `assets/01-dashboard.html`, זהה בכל 5 המסכים הפנימיים.

---

## 1. סיידבר ניווט (ימין)

```html
<aside
  class="fixed right-0 top-0 h-full w-[280px] bg-surface-container-lowest
              z-50 flex flex-col border-l border-outline-variant"
></aside>
```

- רוחב קבוע **280px**, מוצמד לימין, גובה מלא, `z-50`
- רקע לבן, גבול בצד **שמאל** (`border-l`) — זה הגבול הפנימי מול אזור התוכן

### ראש הסיידבר

ריבוע 40×40 ב-`primary-container` (`#001f3f`) עם רדיוס `lg` ואייקון `newspaper` בלבן, ולידו הטקסט **Gilion** ב-`headline-md`/`primary`.

> בעיצוב הנוכחי זה placeholder גנרי. במימוש יש להחליף בלוגו האמיתי (`assets/logo.png`).

### פריטי ניווט

```html
<!-- לא פעיל -->
<a
  class="flex items-center gap-3 px-gutter py-3 rounded-lg
          text-on-surface-variant
          hover:bg-surface-container-low hover:text-on-surface transition-all"
>
  <!-- פעיל -->
  <a
    aria-current="page"
    class="flex items-center gap-3 px-gutter py-3 rounded-lg font-bold
          bg-secondary-container text-on-secondary-container
          border-r-4 border-secondary"
  ></a
></a>
```

הפריטים לפי הסדר, עם ה-`data-path` שנוצר:

| תווית          | אייקון              | `data-path`       | מסך                             |
| -------------- | ------------------- | ----------------- | ------------------------------- |
| דשבורד         | `dashboard`         | `dashboard`       | `screens/01-dashboard.md`       |
| לוח שיבוץ      | `grid_view`         | `layout-board`    | `screens/02-layout-board.md`    |
| הזמנות חדשות   | `add_shopping_cart` | `new-orders`      | `screens/03-new-order.md`       |
| ניהול קבצים    | `folder_open`       | `file-management` | `screens/05-file-management.md` |
| גבייה וחשבונות | `receipt_long`      | `billing`         | `screens/04-billing.md`         |
| לקוחות         | `group`             | `customers`       | _טרם עוצב_                      |
| — קו מפריד —   |                     |                   |                                 |
| הגדרות         | `settings`          | `settings`        | _טרם עוצב_                      |

### פערים מול ה-PRD

הניווט שיצא מ-Stitch לא מכסה את כל המערכת. חסרים:

- **בורר עסק פעיל** — FR-2 דורש בחירת עסק לאחר התחברות כשלמשתמש יש יותר מעסק אחד. אין לזה שום ייצוג בעיצוב. חייב להיכנס לסיידבר, מתחת ללוגו.
- **גיליונות** — "לוח שיבוץ" קופץ ישר לעריכת גיליון בודד. חסר מסך רשימת גיליונות (פתיחת גיליון חדש, סטטוסים, הורדת PDF).
- **הזמנות** — יש "הזמנות חדשות" (יצירה) אבל אין רשימת הזמנות עם אישור/דחייה (US-004).
- **תזכורות** — קיים כווידג'ט בדשבורד בלבד, אין מסך ייעודי.

**ניווט מוצע לאחר השלמה:** דשבורד · לקוחות · הזמנות · מודעות · גיליונות · לוח שיבוץ · גבייה · הגדרות.

## 2. סרגל עליון

פס לבן בגובה ~80px לאורך אזור התוכן (משמאל לסיידבר), עם גבול תחתון `outline-variant`.

מימין לשמאל:

1. אווטאר עגול + שם משתמש דו-שורתי: **מנהל מערכת** (`body-md` bold) מעל `Gilion Admin` (`caption`, `on-surface-variant`)
2. מפריד אנכי
3. אייקון `notifications`
4. אייקון `search`
5. _(דוחף לשמאל)_ צ'יפ `EDITORIAL PORTAL` — `label-sm` ב-JetBrains Mono, רקע `surface-container`, רדיוס `lg`
6. אייקון המבורגר (`menu`)

> הצ'יפ `EDITORIAL PORTAL` הוא טקסט דקורטיבי מ-Stitch. **מועמד טבעי להפוך לבורר העסק הפעיל** — אותו מיקום, אותה צורה, ותוכן אמיתי.

## 3. אזור התוכן

```html
<main class="me-[280px] p-margin-desktop"></main>
```

מרווח של 280px בצד **ימין** (`me-`) כדי לפנות מקום לסיידבר, וריפוד 32px.

מבנה חוזר בתוך `main`:

1. **Breadcrumb** (אופציונלי) — `caption`, מיושר ימין, עם אייקון בית. דוגמה: `🏠 / הזמנות מודעות / הזמנה חדשה`
2. **כותרת עמוד** — `headline-lg` ב-Libre Caslon, לעיתים עם קו תחתון זהב חלקי
3. **תת-כותרת** (אופציונלי) — `caption`/`body-md` ב-`on-surface-variant`
4. **פעולות עמוד** — מיושרות שמאל, באותה שורה של הכותרת
5. **תוכן** — כרטיסים על רקע `surface`

## 4. מעטפת פורטל הלקוח (שונה לחלוטין)

מקור: `assets/06-portal-request.html`

- **אין סיידבר.** פס עליון דק בלבד.
- פס עליון: מימין אייקון `article` + שם העיתון (**העיתון**); משמאל `שלום, אריאל כהן` עם אווטאר עגול.
- תוכן: עמודה ממורכזת ברוחב ~720px.
- מרווחים נדיבים בהרבה מהכלים הפנימיים.
- רקע `surface`, כרטיס יחיד לבן עם רדיוס `xl`.
- כותרת הכרטיס על רקע גרדיאנט עדין תכלת.

הפרדה זו נכונה ומכוונת: FR-9 קובע שלקוח לא נכנס למסכי ניהול פנימיים. המעטפת השונה מחזקת את ההפרדה גם ויזואלית.
