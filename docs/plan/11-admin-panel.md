# שלב 11 — פאנל ניהול

## מטרה

בסוף השלב משתמש בתפקיד `admin` יכול לשנות בעצמו — בלי מפתח ובלי דיפלוי — את זהות המותג של העסק, את ההגדרות התפעוליות ואת הטקסטים שהמשתמשים רואים. שום ערך כזה לא נשאר hardcoded בקוד.

## תלויות

**01** (Auth, RBAC, tenancy) · **05** (תשתית העלאת קבצים ל־MinIO — נעשה בה שימוש חוזר ללוגו).

השלב עצמאי משאר הענף: הוא לא תלוי ב־04, 06, 07.

## מקורות באפיון

הוראת משתמש עומדת — לא נגזר מ־`prd.md`. הדרישה: לכל מערכת שנבנית חייב להיות פאנל ניהול שמאפשר שינוי הגדרות, העלאת לוגו, שינוי צבעים, וכל ערך שמנהל עשוי לרצות לשנות ידנית.

תלוי בקונבנציות: [`conventions.md`](conventions.md) §2 (tenancy), §5 (קבצים פרטיים), §6 (לוג ביקורת), §9 (שכבות).

## Scope

**נכנס:**

- ישות `BusinessSettings` — רשומה אחת לכל עסק, נוצרת אוטומטית עם העסק.
- **מותג:** העלאת לוגו (סימן + לוגו מלא), favicon, שם תצוגה, tagline.
- **צבעים:** דריסת טוקני העיצוב המרכזיים — `primary`, `primary-container`, `brand-gold`, `state-active`, וחמשת צבעי הסטטוס.
- **טקסטים:** כותרת מסך התחברות, טקסט פתיחה בפורטל הלקוח, טקסט תחתית ל־PDF, נוסח ברירת מחדל לתזכורת.
- **הגדרות תפעוליות:** פרטי התקשרות של העסק, אזור זמן, פורמט תאריך, מטבע.
- מנגנון **החזרה לברירת מחדל** לכל שדה בנפרד ולכל הקבוצה.
- **תצוגה מקדימה חיה** של ערכת הצבעים לפני שמירה.

**לא נכנס:** ניהול משתמשים והזמנות לעסק (נשאר בשלב 01) · עורך ערכות נושא חופשי (רק דריסת טוקנים מוגדרים) · העלאת פונטים · מיתוג שונה לכל עיתון בתוך אותו עסק.

## מודל נתונים

ישות אחת חדשה, tenant-scoped ישירות (`conventions.md` §2):

**`BusinessSettings`**

| שדה                         | טיפוס               | חובה | הערות                                 |
| --------------------------- | ------------------- | ---- | ------------------------------------- |
| `id`                        | string              | כן   | Primary key                           |
| `business_id`               | reference: Business | כן   | **ייחודי** — רשומה אחת לעסק           |
| `display_name`              | string              | לא   | ברירת מחדל: `Business.name`           |
| `tagline`                   | string              | לא   |                                       |
| `mark_file_key`             | string              | לא   | מפתח MinIO; `null` = קובץ ברירת המחדל |
| `logo_full_file_key`        | string              | לא   |                                       |
| `favicon_file_key`          | string              | לא   |                                       |
| `color_overrides`           | Json                | לא   | מפתח→ערך hex; מפתח חסר = ברירת מחדל   |
| `text_overrides`            | Json                | לא   | מפתח→מחרוזת                           |
| `contact_phone`             | string              | לא   |                                       |
| `contact_email`             | string              | לא   |                                       |
| `contact_address`           | string              | לא   |                                       |
| `timezone`                  | string              | כן   | ברירת מחדל `Asia/Jerusalem`           |
| `date_format`               | string              | כן   | ברירת מחדל `dd/MM/yyyy`               |
| `currency`                  | string              | כן   | ברירת מחדל `ILS`                      |
| `created_at` / `updated_at` | datetime            | כן   |                                       |

**למה Json ולא עמודה לכל צבע:** מספר הטוקנים ישתנה עם הזמן. `null` או מפתח חסר תמיד אומר "ברירת מחדל" — כך הוספת טוקן חדש לא דורשת מיגרציה ולא נוגעת בעסקים קיימים.

**מפתחות MinIO** לפי `conventions.md` §5: `{businessId}/brand/{mark|logo-full|favicon}.{ext}`.

## מסלולים ופעולות

- `app/(internal)/settings/branding/` — מותג: לוגו, favicon, שם, tagline.
- `app/(internal)/settings/theme/` — צבעים, עם תצוגה מקדימה חיה.
- `app/(internal)/settings/texts/` — טקסטים.
- `app/(internal)/settings/general/` — פרטי התקשרות, אזור זמן, פורמט תאריך, מטבע.
- `lib/data/business-settings.ts` — קריאה וכתיבה, כולל יצירה עצלה של הרשומה בקריאה ראשונה.
- `lib/domain/theme-tokens.ts` — מודול טהור: מיזוג `color_overrides` על טוקני ברירת המחדל, ולידציית hex, בדיקת ניגודיות. ללא Prisma, נבדק ב־Vitest.
- **Server Actions:** `updateBranding` · `updateTheme` · `updateTexts` · `updateGeneral` · `resetSetting(key)`.

**איך הצבעים מגיעים למסך:** ה־root layout קורא `BusinessSettings` פעם אחת ומזריק את הדריסות כמשתני CSS ב־`<body style>`. טוקני Tailwind מוגדרים כ־`var(--token, <default>)`, כך שמפתח שלא נדרס נופל לברירת המחדל בלי קוד תנאי. אין rebuild, אין דיפלוי.

**איך הלוגו מגיע למסך:** רכיב `<BrandMark />` יחיד קורא את `mark_file_key`; אם הוא `null` — מגיש את `public/brand/mark.svg`. **אף רכיב אחר לא מקשיח נתיב ללוגו.** זה מה שהופך את החלפת הלוגו לפעולה של דקה במקום שינוי קוד.

## מסכים

ארבעה מסכים תחת מעטפת ההגדרות הפנימית, לפי הקו העיצובי הקיים ([`../design/design-system.md`](../design/design-system.md), [`../design/components.md`](../design/components.md)) — הם נוספים ל־8 המסכים החסרים ב־[`../design/gaps.md`](../design/gaps.md) §ג:

1. **מותג** — אזור גרירה להעלאת קובץ (הדפוס ממסך 05), לצדו תצוגה מקדימה של הסימן ב־40×40, 80×80 ובגודל מלא, על רקע בהיר וכהה. זה מה שמראה מיד אם הלוגו עובד כ־UI chrome.
2. **צבעים** — רשימת טוקנים, לכל אחד בורר צבע + שדה hex + כפתור "אפס". מימין תצוגה מקדימה חיה של סיידבר, כרטיס KPI ושלושה badge סטטוס.
3. **טקסטים** — טופס שדות טקסט, כל שדה עם ה־placeholder של ברירת המחדל.
4. **כללי** — פרטי התקשרות, אזור זמן, פורמט תאריך, מטבע.

בכל ארבעתם: כפתור שמירה יחיד, מצב "נשמר", ומצב ריק שמסביר מה קורה כשלא משנים כלום.

## הרשאות

- **`admin` בלבד** — קריאה וכתיבה בכל ארבעת המסכים.
- `sales`, `designer`, `accounting` — אין גישה למסלול `settings/`; ניסיון כניסה מחזיר 403.
- `customer` — אין גישה. פורטל הלקוח **קורא** את הצבעים והלוגו (כדי שהמיתוג יופיע גם שם) אבל אינו יכול לשנותם.
- כל ארבע הפעולות עוטפות ב־`withAudit()` ([`conventions.md`](conventions.md) §6) — שינוי מיתוג הוא שינוי גלוי לכל המשתמשים ולכן חייב עקבות.

## כללי ולידציה

- **קובץ לוגו:** `svg`, `png`, `webp` בלבד. עד 2MB. SVG עובר sanitize (הסרת `<script>`, `on*`, `<foreignObject>`) לפני שמירה — SVG הוא קוד, לא תמונה.
- **favicon:** `ico`, `png`, `svg`. עד 200KB.
- **צבע:** hex תקין (`#rgb` / `#rrggbb`) בלבד.
- **ניגודיות:** צבע טקסט על רקע שנופל מתחת ל־WCAG AA (4.5:1) מציג **אזהרה** ולא חוסם — זה העסק של המנהל, אבל הוא צריך לדעת.
- **אזור זמן:** ערך תקין מ־`Intl.supportedValuesOf('timeZone')`.
- כל השדות עוברים `zod` **בשרת** ([`conventions.md`](conventions.md) §9).
